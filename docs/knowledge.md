# 問題解決ナレッジ

## 目的

レビューでの指摘やエージェントとのやり取りで発生したトラブルから、同様の問題を
解決・予防するために再利用できる行動知を記録する。

## 記録基準

- 原因と解決方法が確認され、実際の結果で検証されている
- 特定の会話や一時的な状況に限定されず、今後の作業で再利用できる
- 実行すべき行動と、その結果を確認する方法が具体的である
- 既存の項目と重複していない

未解決の仮説、作業中のメモ、会話ログ、指摘者名、シークレットや個人情報は記録しない。

## 記載形式

新しい項目は新しい日付順で追加する。同じ問題に関する学びが存在する場合は、項目を
増やさず既存の内容を更新する。

```markdown
## YYYY-MM-DD: 短い題名

- 状況: 問題が発生した条件や前提
- 問題: 観測された指摘またはトラブル
- 原因: 検証によって確認した直接原因
- 解決行動: 次回実行すべき具体的な手順
- 検証: 解決を確認した方法と結果
- 適用範囲: この学びを適用する条件や対象
- 関連: 関係するルール、文書、テスト、Issueなど
```
