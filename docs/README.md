# ドキュメントガイド

プロジェクトの要件・仕様に関するドキュメントの一覧です。
新しいドキュメントを追加した場合は、下記の表にも追記してください。

## ドキュメント一覧

| ドキュメント | 概要 | ステータス | 最終更新日 |
| --- | --- | --- | --- |
| [index.md](./index.md) | OKF準拠のドキュメント索引 | Fixed | 2026-09-19 |
| [log.md](./log.md) | ドキュメントの更新履歴 | Fixed | 2026-09-19 |
| [architecture.md](./architecture.md) | 全体構成・データモデル・環境・インフラ構成・制約 | Draft | 2026-09-19 |
| [directory.md](./directory.md) | リポジトリのディレクトリ構成 | Draft | 2026-09-19 |
| [knowledge.md](./knowledge.md) | レビュー・エージェント間の問題解決ナレッジ | Draft | 2026-09-19 |
| `requirements.md` | 要件定義（機能要件・非機能要件） | TBD | - |
| `specs/` | 機能ごとの詳細仕様 | TBD | - |

### ステータスの定義

| ステータス | 意味 |
| --- | --- |
| TBD | 未作成（作成予定） |
| Draft | 作成中・レビュー前 |
| Review | レビュー中 |
| Fixed | 確定済み |
| Deprecated | 廃止（参照非推奨） |

## ドキュメント追加時のルール

- ファイル名は英小文字のケバブケース（例: `api-design.md`）とする
- 追加・更新時は上記一覧の「ステータス」「最終更新日」を更新する
- 機能単位の仕様は `specs/` 配下に配置する
