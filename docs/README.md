# ドキュメントガイド

文書の入口と一覧の正本は[index.md](index.md)。必要な文書だけを参照する。
このガイドは管理方法を扱い、一覧・状態・更新日を重複管理しない。

## ステータスの定義

| ステータス | 意味 |
| --- | --- |
| TBD | 未作成（作成予定） |
| Draft | 作成中・レビュー前 |
| Review | レビュー中 |
| Fixed | 確定済み |
| Deprecated | 廃止（参照非推奨） |

## ドキュメント更新時のルール

- `docs/`は要件・設計・運用知識の正本を置くOpen Knowledge Format（OKF）v0.2バンドルとする。
- 概念文書はUTF-8のMarkdownとし、先頭のYAML frontmatterに空でない`type`を含める。`index.md`と`log.md`は予約ファイル名として扱う。
- ファイル名は英小文字のケバブケース（例: `api-design.md`）とする
- 要件・設計・運用などの永続的な知識が変わる場合は、実装と同じ変更で該当文書を更新する
- 配置・設定の手順は現在の構成を前提に記載し、廃止済みの構成や移行経緯を混在させない
- 追加・移動・削除時は索引を同期し、追加・更新時は索引の状態と最終更新日（JST）を更新する
- 重要な知識変更は[log.md](log.md)の先頭の日付節に記録する
- タスクの進捗、一時的な調査メモ、未確認の推測、秘密情報・認証情報は記録しない
- 正本がある内容を別文書に複製せず、索引や関連文書から案内する
- 機能単位の仕様は `specs/` 配下に配置する
