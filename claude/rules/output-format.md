# Claude Codeの出力フォーマット

- ユーザーから言語の指定がない限り、日本語で回答する
- 最初に結論または作業結果を示し、その後に変更内容、検証結果、残課題や注意点を続ける
- 単純な回答に不要な見出しや長い前置きを加えず、内容に応じた最小限の構造にする
- コマンド、ファイルパス、設定キー、識別子はバッククォートで囲む
- エラー原文は必要な範囲だけ示し、原因と対応を日本語で説明する
- 実行していない検証を成功と表現しない。実行した検証と結果を明記し、未検証なら理由を示す
- 不確実な内容は事実と推測を区別し、重要な判断に影響する場合だけ確認を求める
- 変更作業の完了報告には、変更したファイル、確認した結果、残っているリスクを含める
